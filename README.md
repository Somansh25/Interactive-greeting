# 🎈 Interactive Animated Greeting Experience

A production-ready, mobile-first web application designed for custom celebratory greetings (birthdays, holidays, anniversaries). Built with a **Flask** backend and an **HTML5 Canvas** rendering engine powered by native **Web Audio API** sound synthesis.

---

## ✨ Features

- 🎆 **3-Stage Canvas Physics Engine**: Fireworks launch upward, detonate into glowing text characters, and transform into floating balloons.
- ⌨️ **Live Debounced Typing**: Updates text on-screen in real time as you type with zero page reloads.
- 🎨 **Dynamic HSL Color Themes**: Switch instantly between *Neon Party*, *Cyberpunk*, *Pastel Dream*, and *Fire & Gold*.
- 🔊 **Native Sound Synthesizer**: Custom synthesized audio for pops, explosions, and celebratory chimes using Web Audio API—no external audio assets required.
- 🎈 **Interactive Mini-Game**: Tap or click floating balloons to pop them, triggering spark bursts and incrementing a live counter.
- 💨 **Cursor & Touch Wind Interaction**: Balloons dynamically sway away from touch/cursor movements.
- ⏸️ **Animation Controls**: Play, pause, or mute animations seamlessly.
- 🔗 **Shareable URL Parameters**: Generate dynamic URLs containing custom greetings and themes to share with friends.
- 📱 **Mobile-First Glassmorphism UI**: Responsive HUD overlay designed for touch targets (minimum 44px) across all screen sizes.
